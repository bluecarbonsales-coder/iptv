THREE SEPARATE LISTS

Source settings

Turn sources on or off, add a source, delete one, or use Enable all. Settings are saved on this server.

Radio sources

The Radio Browser directory is included by default. Add individual station stream URLs below; M3U playlists are managed under IPTV.

IPTV playlist sources

Add an M3U/M3U8 playlist URL. The server validates the playlist and refreshes the IPTV catalogue. The main iptv-org catalogue stays available as the built-in source.

Theatre video sources

The bundled provider list is enabled by default. Add a compatible Apple CMS/MacCMS VOD API, or import a compatible provider-list JSON URL.

Source endpoints are stored on the server. Enable all is convenient while testing; some external links may stop working or return content you do not expect.
