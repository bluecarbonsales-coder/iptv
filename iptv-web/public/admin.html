THREE SEPARATE LISTS

Source settings

Manage every Radio, IPTV and Theatre source here, including availability, counts, network RTT and relay latency.

Source availability & latency

Relay latency measures the app server to the source. Current-network RTT measures your browser to the source host; some hosts or browsers block direct checks.

Sign in to load source status.

Administrator account

There is one administrator account. Change the username and password here; changes are saved on the server and survive restarts.

Playback defaults

Radio sources

The Radio Browser directory is included by default. Add individual station stream URLs below; M3U playlists are managed under IPTV.

IPTV playlist sources

Add an M3U/M3U8 playlist URL. The server validates the playlist and refreshes the IPTV catalogue. The main iptv-org catalogue stays available as the built-in source.

Theatre video sources

The bundled provider list is enabled by default. Add a compatible Apple CMS/MacCMS VOD API, or import a compatible provider-list JSON URL.
