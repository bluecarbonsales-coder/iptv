AGENT CONTROL PLANE

Media sources and navigation

Hermes is the configuration editor for this portal. Public pages are read-only; this page intentionally does not accept management tokens or perform source changes from a visitor browser.

What Hermes can manage

  • IPTV playlists and M3U/M3U8 sources: add, validate, replace, enable, disable and remove.
  • Movie, series, anime and documentary API providers: add, probe, edit, enable, disable, import and remove.
  • Theatre sidebar navigation and homepage service shortcuts.
  • Metadata/discovery settings, source registry schedules, and project UI/code when runtime configuration is insufficient.
  • Opt-in aggregate visitor trends to prioritize relevant local resources.

Hermes API endpoints

Hermes must send X-Agent-Token in the request header. Keep the token in the agent's secret environment; never put it in browser JavaScript, query strings, source URLs, or Git commits.

Safe operating rules

  • Check compatibility before enabling a source and keep uncertain sources disabled.
  • Use official, public-domain, open-license, and documented sources wherever possible.
  • A successful API probe is not proof of streaming rights.
  • Use only coarse, explicitly shared visitor context. Do not collect exact addresses, raw IPs, precise GPS coordinates, or per-person viewing histories.
  • Before code deployments, run the project tests and preserve the persistent data volume and deployment environment.
